# IELTS Learning Platform

**Live App**: [https://ieltsnepal.netlify.app/](https://ieltsnepal.netlify.app/)

A comprehensive, modular IELTS study platform built to function as an interactive, digital notebook. The project focuses on structured grammar lessons with high-quality pedagogical features to help users master English for the IELTS exam in a self-paced, academic environment.

## Features

- **Structured Grammar Lessons**: Covers essential topics such as Tenses, Subject-Verb Agreement, and Articles.
- **Interactive Practice Quizzes**: Test your knowledge immediately after learning.
- **Text-to-Speech System**: Accessible read-aloud system to enhance listening skills and pronunciation.
- **Real-time Progress Tracking**: Monitor your mastery of different topics.

## Tech Stack

- **React 18**: Core framework for building the UI.
- **TypeScript**: Ensuring type safety and scalable code.
- **Vite**: Ultra-fast build tool and development server.
- **Lucide React**: For sleek, modern iconography.

## Getting Started

### Prerequisites

Make sure you have Node.js and npm (or pnpm/yarn) installed.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Biswaa000/ielts_study.git
   cd ielts_study
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open your browser and visit `http://localhost:5173` to view the app.

## Project Structure

- `/src/components`: Reusable UI components.
- `/src/utils`: Helper functions and utilities (e.g., text-to-speech engine).
- `/src`: Main application source code.
